# 冷愁藏书馆

个人实体藏书档案。暖白色图书馆与藏品档案风格，无需前端构建或数据库。

## 已有功能

- 三十九册实体书、八十张原始照片（含两张系列套装照片）；页面保留完整实拍构图，目录使用缩略预览，详情使用清晰预览，放大查看加载原图。
- 书名、作者、译者、ISBN、编号、出版社与标签搜索。
- 单一主分类筛选，封面和表格视图，入库时间、书名和定价排序。
- 独立单书链接，如 `#book/LC-000001`；原始正反照片、放大查看。
- 入库时间线、关于页面、当前筛选结果的 CSV 导出。
- 手机端布局、键盘操作和减少动态效果偏好。
- 系列分组、系列筛选、同系列单册跳转；横版画册保留比例。

## 本地查看

在本目录执行：

```bash
python3 -m http.server 8080 --directory dist
```

浏览器访问 `http://localhost:8080`。不要直接双击 index.html，浏览器可能拦截 JSON 数据读取。

## 成色记录

每册的 `condition` 包含外观成色、可见磨损说明、评估范围、来源和日期。全部按正反面照片预估外观，单册保留可见磨损说明。列表、详情与 CSV 均显示成色；内页、装订、缺页、笔记和霉斑等未检查。

## 更新藏书

书目位于 `dist/data/books.json`。每本书保留固定编号，主分类可以调整。

照片放在 `dist/assets/LC-000001/` 这类目录内：

| 文件 | 用途 |
| --- | --- |
| thumbnail.webp | 旧版衍生缩略图，当前不用于页面 |
| front.webp / back.webp | 旧版校正衍生图，当前不用于页面 |
| front-original.jpg / back-original.jpg | 保留相机水印的原始照片 |

修改 JSON 后执行 `python3 scripts/validate_catalog.py`；JavaScript 修改后可运行 `node --check dist/app.js`。

`scripts/prepare_assets.py` 是首批照片的处理记录，依赖 Pillow。照片已经处理完成，无需再次运行；如需重新处理，执行 `python3 scripts/prepare_assets.py --source /path/to/photos`。此脚本不会覆盖原始输入文件。

### 数据约定

- `id`：固定藏书编号，一册一个；ISBN 不是实体册唯一标识。
- `listPrice`：封底定价；`paidPrice`：实际支付价格，未知为 `null`。
- `purchaseDate`：可用 `2023`、`2023-06`、`2023-06-15`，分别配 `purchaseDatePrecision` 的 `year`、`month`、`day`。
- `purchaseChannel`：日后补充的购买渠道，未知为 `null`。
- `readingStatus`：未知为 `null`；可填写“未读”“在读”“已读”等真实状态。
- `location` / `notes`：存放位置和个人备注，未知为 `null`。
- `accessionedAt`：首张正面照片的拍摄时间，带 `+08:00` 时区。
- `photos[].capturedAt`：每张照片各自的时间；`timeSource` 保存时间来源。
- 首批时间来自照片文件名，水印核对至分钟，无可读取 EXIF。秒数精度来自文件名。
- 第二册“第三版”仅录入 `coverEditionLabel`，具体出版版次尚待版权页确认。
- 每本书的简介为简短编目概述，非全文内容或个人读后评价。

## 第二批入库与系列

2026-10-18 追加十册：腾讯游戏开发精粹三册，网易游戏学院游戏研发入门系列七册。全部册数为十九册，原始照片三十八张；Tencent 分组是按同名书系归组，网易分组来自封面丛书标识，均仅展示已藏册数，不声称集齐。

- `seriesGroups`：聚合分组定义；`seriesGroupId`、`seriesNumber`、`seriesLabel`：单册系列关联和册序。
- `series`：书目上的丛书或明确标示的系列归组名；不与分类混用。
- `purchaseGroupId`：独立的购买套装关联，当前为空，不推断同一丛书为同次购买。
- `orientation`：横版画册使用 landscape，缩略图、单书图和放大查看都保留比例。
- `photos[].sha256`：第二批原始文件的 SHA-256，防止传输或后续操作改变原始照片。

可运行 `python3 scripts/audit_catalog.py` 检查同图、同 ISBN、同名不同版本。重复项仅报告，由人判断是补拍还是另一本实体册，不自动删书。

第二批导入脚本为 `scripts/import_batch_20261018.py --source /path/to/photos`，依赖 Pillow。原始照片逐字节保留。脚本生成的校正衍生资源仅作历史保留；当前封面目录、表格、入库记录、详情和放大查看均使用 original 原图，保留自然倾斜、完整背景及磨损。

## 目录与展示优化

首页列出最近入库的六册，支持按最新入库浏览；语种筛选与类别、系列、搜索组合使用，系列快捷导航直接进入对应书组。单册藏书独立成组。详情页优先展示已录入信息，空字段集中在“待补信息”折叠区；原始照片按比例完整展示。装饰性英文已移除，原文书名、作者、版本与 ISBN 等实质信息保留。后续 GitHub 提交说明统一使用中文。

## 手机体验与用途标签

600px 及以下筛选默认收起，显示已选条件数，支持展开、清除和查看结果。手机表单与照片按钮扩大触控范围，长书名自然换行，图片保持原图完整比例；放大查看适应移动屏幕与安全区域。

`usageTags` 为个人编目的参考用途，与主题分类分开记录；按书目主题初步判断，可随阅读调整。目录卡片、表格和详情显示，支持用途下拉筛选、全文检索、详情标签查找同用途藏书与 CSV 导出。

## 图片加载与预览生成

- 仅保留原图陈列架，不再设置主题切换或本地主题记忆。
- 目录封面与最近入库使用 480 像素宽的 WebP 缩略预览；详情使用 960 像素宽的 WebP 预览；放大查看时才请求原始照片。
- 预览只缩小并压缩完整画面，不裁切、不调正、不重绘，原图保持不变。
- 最近入库前两张优先加载，其他目录图片按浏览器延迟加载；图片使用异步解码和固定占位。
- GitHub Pages 工作流先运行 `scripts/optimize_photos.py`，再校验和发布。预览图从仓库已有原图生成，不重复提交到 Git。
- 本地预览前安装工作流所列 Pillow 版本，运行 `python scripts/optimize_photos.py`。
