# 2026-11-03 武侠书名核对

以馆藏原版本的实物照片为主要依据，馆藏目录及出版社序文作交叉核对。没有找到可逐册查询旧版53册古龙的出版社官方在线目录，不能把其他年份的书目直接套用于本套。此次没有进行正版鉴定，也没有根据书名推定版次。

| 版本 | 核对结果与处理 |
| --- | --- |
| 太白文艺出版社《古龙作品全集》53册 | 对照已上传的53册封面，移除人工加在主标题前的丛书册号；实际系列标题及分册结构保留。“小李飞刀系列”“江湖人系列”转为子系列信息，以实际作品名作为主标题；第18、19、20、22、25、26、33、39、41、43、45、47、51、53册的合收作品单列为“本册另收”。 |
| 生活·读书·新知三联书店《金庸作品集》36册 | 12部作品及其分册数量符合该版书目；作品名保留，26册数字分册标识由“第一册”等统一为“（一）”等。两册作品原有上下册标识保留。封面不显示册号的书仍依据既有拍摄顺序编排，不声称逐册书脊已核验。 |
| 北岳文艺出版社《蜀山剑侠传》十卷本 | 正式书名保留；封面有“第一卷”至“第十卷”，据此统一卷号。出版社序文说明后传等整合在本书正文中，不能把末卷直接改名为《蜀山剑侠后传》。 |
